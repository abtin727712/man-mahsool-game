# بازی «من چه محصولی هستم؟» — پروژه اندروید

این پروژه شامل بازی فارسی با حالت انفرادی و گروهی و ۳۰ معما است. برنامه از یک صفحه HTML داخل WebView اندروید استفاده می‌کند.

## ساده‌ترین روش ساخت APK بدون نصب Android Studio

در پوشه `.github/workflows` یک گردش‌کار آماده قرار دارد که می‌تواند فایل APK را در GitHub بسازد.

1. در GitHub یک مخزن جدید (Repository) بسازید.
2. محتوای این پوشه را در مخزن بارگذاری کنید؛ فایل‌ها باید در ریشه مخزن باشند و پوشه‌های `.github` و `app` هم حفظ شوند.
3. وارد زبانه **Actions** مخزن شوید.
4. اگر لازم بود، تأیید اجرای GitHub Actions را انجام دهید.
5. گردش‌کار **Build Android APK** را اجرا کنید. اگر به‌صورت خودکار شروع نشده، در صفحه آن گزینه **Run workflow** را بزنید.
6. پس از پایان موفق، در همان اجرای گردش‌کار بخش **Artifacts** را پیدا کنید و فایل `ManMahsoolHastam-debug-apk` را دانلود کنید.
7. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` داخل آن است.
8. فایل APK را به گوشی اندرویدی منتقل و باز کنید. اگر گوشی اجازه نصب از آن منبع را خواست، فقط در صورت اطمینان از منبع فایل، اجازه نصب را فعال کنید.

## ساخت با Android Studio

1. Android Studio و Android SDK Platform 35 را نصب کنید.
2. از **File > Open** پوشه اصلی پروژه را باز کنید؛ همان پوشه‌ای که فایل‌های `settings.gradle` و `build.gradle` در آن هستند.
3. پس از آماده شدن Gradle و SDK، از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کنید.
4. فایل خروجی معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## نکات

- این پروژه فایل APK از پیش کامپایل‌شده ندارد؛ این بسته پروژه آماده ساخت است.
- فایل خروجی `debug` برای نصب و آزمایش شخصی مناسب است، اما برای انتشار رسمی در فروشگاه‌ها باید نسخه release و امضای مناسب تهیه شود.
- برای روش GitHub، لازم است حساب GitHub داشته باشید و پروژه را در مخزن خودتان بارگذاری کنید.
